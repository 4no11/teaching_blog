关于师备云

📚 项目简介

师备云是一个专为教师设计的知识分享平台，旨在帮助教师发布教学笔记、分享教育资源、交流教育心得。

✨ 主要功能
  • 📝 教学笔记 - 记录和分享日常教学经验
  • 📚 教育资源 - 上传和分享优质教学资源
  • 💡 教育心得 - 交流教育理念和方法
  • 🤖 AI助手 - 集成大模型，智能辅助教学
  • 💬 评论互动 - 读者评论和互动交流
🛠️ 技术栈
  • 后端: Flask + Python
  • 模板: Jinja2
  • 数据库: MySQL
  • 前端: Bootstrap 5
  • AI集成: OpenAI API / 兼容接口
本系统使用简单，界面友好，适合各类教育工作者使用。
